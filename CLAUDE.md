# gi's digital garden

Astro site. Content in `src/content` is rsync'd from an Obsidian vault — edit it
there, not in this repo.

**Before writing any CSS, component, or visual change, read [DESIGN.md](DESIGN.md).**
It is the design system: token locations, the house style, and the non-negotiable
rules (no hardcoded values, no emoji, both themes, DRY).

Feature requests phrased "feature to do: X" get appended to `FEATURES.md`.
Commit directly to `main`.
